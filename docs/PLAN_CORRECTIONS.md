# Корректировки плана под новые требования

> **Статус:** Корректировки применены в `PLAN.md` и `docs/stages/*`. Файл сохранён как журнал решений.

## Контекст

**Новая задача:** создать современный сайт, представляющий компанию по ремонту техники Apple.

**Новые требования:**
- Стиль: **минимализм**
- Цвета: **белый, чёрный, оттенки серого**
- Хорошая **мобильная версия**
- Возможно **анимация при загрузке**

**Обнаруженные сайты организации:**
1. **avatech.info** — Genius Lab (ex AvaTech)
2. **assistenza-macbook.it** — Apple Assistenza Roma, AvaTech Lab, блог
3. **apple-assistenza.it** — AvaTech, Chi Siamo, Recensioni (корзина не переносится)

Все три сайта — одна компания. Контент частично дублируется, структура различается. **Финальный бренд:** Genius Lab.
