# План: вывести `riparazione macbook` в top-10

## Цель
- Сделать `https://geniuslab.info/servizi/riparazione-macbook` главным URL под запрос `riparazione macbook roma`.
- Убрать размывание сигнала между старыми и новыми URL.
- Усилить страницу контентом, локальными сигналами и внутренними ссылками.

## Приоритет 1. Технический каркас
- Зафиксировать один канонический URL для MacBook-услуги: `/servizi/riparazione-macbook`.
- Проставить `301` с `/servizi/macbook` и других legacy-вариантов на этот URL.
- Убедиться, что canonical, hreflang и sitemap указывают на канонический адрес.
- Исключить дубликаты этого интента из sitemap.

## Приоритет 2. Контент страницы
- Усилить `answerFirstIntro` под запрос `riparazione MacBook Roma`.
- Добавить блок с моделями MacBook, которые обслуживаются.
- Добавить блок с тезисами о сроках, цене, гарантии и процессе.
- Расширить FAQ вопросами про цену, сроки, модели и локацию.
- Уточнить `metaDescription` и keyword-сигналы под локальный интент.

## Приоритет 3. Внутренняя перелинковка
- Сделать ссылку на MacBook-страницу из главной и страницы услуг.
- Использовать якоря, близкие к запросу: `Riparazione MacBook Roma`, `Riparazione MacBook`.
- Следить, чтобы внутренние ссылки вели только на канонический URL.

## Приоритет 4. Schema и доверие
- Проверить `Service`, `FAQPage` и `BreadcrumbList` на канонической странице.
- Добавить локальные доверительные сигналы: адрес, часы, гарантия, реальный сервис.
- При необходимости добавить реальные фото и alt-тексты.

## Приоритет 5. Проверка и контроль
- Проверить, что старые URL теперь отдают `301`, а не `404`.
- Запросить переобход в Google Search Console.
- Отслеживать `riparazione macbook`, `riparazione macbook roma` и похожие запросы в Performance.
- Не плодить новые почти одинаковые страницы под тот же интент.

## Порядок работ
1. Технический canonical/redirect cleanup.
2. Усиление страницы MacBook.
3. Перелинковка с главной и сервисного хаба.
4. Проверка GSC и итерации по контенту.
