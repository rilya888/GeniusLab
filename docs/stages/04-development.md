# Этап 4: Разработка фронтенда

[← К общему плану](../PLAN.md)

## Цель этапа

Реализовать фронтенд на выбранном стеке по макетам и архитектуре.

## Входные данные

- Документ архитектуры (этап 02)
- Figma/макеты, design tokens (этап 03)
- Дизайн-спецификация Liquid Glass (`docs/DESIGN_SPEC.md`)
- Sitemap, схема компонентов
- P1 design pack (top 10 страниц)
- Component interaction contract и словарь аналитических событий
- Placeholder source spec (контакты/legal/соцсети)

## Задачи

1. **Настройка проекта и сборки**
   - Инициализация проекта (выбранный стек)
   - Инициализация на Astro (SSG-first архитектура)
   - Сборка, линтинг, форматирование
   - Подготовка структуры словарей для i18n (default locale: it)
   - Настройка окружений для Railway (dev/stage/prod)

2. **Базовые компоненты**
   - Header (навигация, CTA, мобильное меню)
   - Footer (контакты, ссылки)
   - CTA-кнопки (звонок, WhatsApp)
   - Карточки услуг
   - Единый иконсет (Lucide) по правилам дизайн-системы
   - Glass-компоненты: surface panels, glass buttons, overlay layers

3. **Страницы**
   - Главная
   - Услуги (список + отдельные страницы)
   - Контакты
   - Recensioni (отзывы)
   - Chi Siamo (при необходимости)
   - Реализация в две волны: сначала P1 top 10, затем остальные

4. **Адаптивность и доступность**
   - Mobile-first, breakpoints
   - a11y: WCAG 2.1 AA (контраст, фокус, семантика, aria)
   - Touch targets: минимум 44x44 px
   - Поддержка браузеров: Safari iOS 16+, Chrome Android 110+, desktop Safari/Chrome/Edge/Firefox (последние 2 версии)

5. **Интеграция форм**
   - Контактная форма
   - Форма записи на приём
   - Отправка на email (Formspree / Netlify Forms / backend)
   - Антиспам (honeypot и/или captcha, базовый rate limit)
   - Логирование ошибок отправки и fallback email
   - Единый success-сценарий после отправки формы
   - Единый контракт полей и валидации для переиспользования в будущих интеграциях

6. **Интеграция Google Reviews**
   - Виджет или embed на странице Recensioni
   - Fallback-состояние без внешней кнопки перехода
   - Устойчивый рендер блока (ошибка виджета не ломает layout страницы)

7. **Карта**
   - Google Maps на странице контактов (Viale Somalia, 246)

8. **Комментарии в коде**
   - Только на английском языке

9. **Анимация и performance budget**
   - Лёгкие CSS-анимации (`opacity`, `transform`) для входа контента
   - Учет `@media (prefers-reduced-motion: reduce)`
   - Избегать тяжёлых JS-анимаций
   - Анимация не должна ухудшать FCP/LCP/INP
   - Glass-эффекты реализовывать с ограничением blur и с graceful degradation на слабых устройствах
   - Не использовать перманентные эффекты, провоцирующие дорогой repaint/scroll jank

10. **SEO и семантическая готовность**
   - Семантическая HTML-структура для страниц услуг и контактов
   - Технические слоты/точки подключения для metadata, OG и schema.org
   - Поддержка canonical и hreflang-ready структуры (для будущих локалей)

11. **Аналитика и consent-интеграция**
   - Реализация event hooks по контракту (CTA click, form submit success/fail)
   - Гейтинг событий аналитики через consent-статус
   - Базовая трассировка ошибок форм для мониторинга

12. **Дополнительные обязательные элементы v1**
   - Favicon и web app icons
   - Кастомная страница 404 в общем стиле сайта
   - Footer: placeholders для соцсетей (Facebook/Instagram/YouTube)
   - WhatsApp CTA с шаблоном сообщения (placeholder номера)

13. **Visual regression и устойчивость UI**
   - Baseline-скриншоты для P1 страниц (mobile + desktop)
   - Проверка регрессий glass-стилей перед релизом
   - Правило отказоустойчивости: при сбое Google Reviews/Maps страницы остаются полностью usable

## Результаты

- **Рабочий фронтенд** — все страницы, компоненты, формы
- **Компонентная библиотека** — переиспользуемые модули
- **Документация компонентов** — для поддержки и расширения
- **P1 delivery report** — отчёт по реализации top 10 страниц
- **Frontend integration notes** — как подключены SEO/analytics/legal точки

## Связи с другими этапами

- **Контент и SEO** — встраивает тексты и разметку
- **Legal Compliance** — добавляет cookie banner, consent в формы
- Формы собирают данные — требуется согласие пользователя (Privacy Policy)

## Критерии готовности

- [ ] Все страницы реализованы и работают
- [ ] P1 top 10 страницы реализованы и проверены первыми
- [ ] Формы отправляют данные на email
- [ ] Формы защищены от базового спама
- [ ] Google Reviews отображаются
- [ ] Карта на странице контактов
- [ ] Адаптивность проверена
- [ ] Базовая доступность (a11y) соблюдена
- [ ] Строки интерфейса вынесены в словари (it)
- [ ] Типографика реализована через SF Pro system stack (без webfont-файлов)
- [ ] Анимации реализованы с учетом reduced-motion
- [ ] Glass-эффекты реализованы с graceful degradation и без деградации CWV
- [ ] Мобильная версия проверена минимум на 2 реальных устройствах
- [ ] Реализованы favicon и кастомная 404
- [ ] События аналитики работают по контракту и уважают consent
- [ ] SEO/Schema точки подключения реализованы и готовы к этапу 05
- [ ] Проверена поддержка целевых браузеров (policy выполнена)
- [ ] Baseline-скриншоты P1 созданы и используются для visual regression
- [ ] При сбое внешних виджетов (Reviews/Maps) страницы остаются usable
