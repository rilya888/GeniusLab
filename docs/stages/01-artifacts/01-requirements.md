# Этап 01 — Документ требований (v1 baseline)

## Функциональные требования

1. Единый сайт на `geniuslab.it` с переносом релевантного контента с 3 доменов.
2. Основные страницы: Home, Servizi (лист + детальные), Contatti, Recensioni, Chi Siamo.
3. Формы: contact + appointment, отправка на email, consent checkbox.
4. CTA-каналы: телефон и WhatsApp.
5. Блок отзывов: только Google Reviews (без ручного переноса старых текстовых отзывов).
6. Карта контактов (Google Maps) с корректным отображением двух точек (Lab/Store).
7. One-to-one 301 migration со всех 3 доменов по карте редиректов.

## Нефункциональные требования

1. Mobile-first UX на целевых браузерах из `PLAN.md`.
2. Базовые цели CWV: LCP < 2.5s, INP < 200ms, CLS < 0.1.
3. GDPR-by-design: analytics/cookies только после consent.
4. Контентное единообразие NAP/hours между UI + schema + GBP.
5. Готовность к i18n на уровне словарей (релизный язык IT).
6. Резерв под будущий блог/CRM без включения в v1.

## SEO/миграционные требования

1. Сохранить intent текущих коммерческих URL, особенно `/service/*`.
2. Canonical и metadata на всех целевых страницах.
3. Полный one-to-one mapping для P1-пула до cutover.
4. Удалить/переписать дублирующие и слабые SEO-блоки.
5. Отдельный контроль рисков для `apple-assistenza.it` из-за поломанных `robots/sitemap`.

## Ограничения и допущения

- Финальные реквизиты и часть контактных данных приходят от owner позже.
- Юридические формулировки про Apple не публикуются без legal sign-off.
- Этап 01 не включает разработку кода сайта, только базу для этапа 02.
